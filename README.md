# Sungold Store — قالب بازار ۴ + اپ مدیریت

دو بخش در یک مخزن:

| پوشه | چیست |
|---|---|
| `theme/bazar` | قالب وردپرس/ووکامرس (راست‌چین، موبایل‌اول) با **API تنظیمات** و پیش‌نمایش زنده |
| `app` | **وب‌اپ قابل نصب (PWA)** که همه‌ی تنظیمات ظاهری قالب را از روی گوشی کنترل می‌کند |
| `tools` | سرور آزمایشی (بدون وردپرس)، تست‌ها و چک‌کننده‌ی PHP |
| `capacitor.config.json`، `assets/` | بسته‌بندی اپ به‌صورت APK اندروید (workflow: `android.yml`) |

## راه‌اندازی (۵ قدم)

1. **قالب:** فایل `bazar-theme.zip` را از بخش *Actions → آخرین اجرا → Artifacts* بردارید و در وردپرس نصب و فعال کنید.
   (یا پوشه‌ی `theme/bazar` را به‌صورت zip کنید.)
2. **فونت:** فایل `Vazirmatn-Variable.woff2` را در `theme/bazar/assets/fonts/` و `app/fonts/` بگذارید.
3. **اپ:** در GitHub: *Settings → Pages → Source: GitHub Actions*. بعد از اولین push روی `main`، اپ در `https://<user>.github.io/<repo>/` منتشر می‌شود.
4. **رمز برنامه:** پیشخوان وردپرس ← کاربران ← پروفایل ← «رمزهای عبور برنامه» ← نام `Sungold App` ← افزودن ← رمز را کپی کنید.
5. **اتصال:** اپ را باز کنید، آدرس سایت + نام کاربری + رمز برنامه را وارد کنید. روی گوشی «افزودن به صفحه‌ی اصلی» بزنید.

> سایت باید **HTTPS** داشته باشد (Application Passwords روی HTTP کار نمی‌کند).

## چه چیزی از اپ قابل کنترل است؟

همه‌چیز از `theme/bazar/inc/schema.json` ساخته می‌شود؛ **تنها منبع حقیقت** برای قالب، API و فرم‌های اپ. فیلد جدید = یک آبجکت در همین فایل.

| بخش | تنظیمات |
|---|---|
| هویت | نام فروشگاه، شعار، لوگو، آیکن سایت |
| رنگ و ظاهر | ۵ پالت آماده، ۴ رنگ (اصلی/تأکید/متن/تخفیف)، گردی گوشه‌ها. بقیه‌ی رنگ‌ها **خودکار** با تضمین خوانایی ساخته می‌شوند |
| هدر و فوتر | نوار بالا، ناوبری پایین موبایل، تلفن/واتس‌اپ/اینستاگرام/تلگرام/ایمیل، متن فوتر و کپی‌رایت |
| صفحه اصلی | **ترتیب و روشن/خاموش‌کردن بخش‌ها**، هیرو (متن، دکمه‌ها، حالت رنگی)، محصولات ویژه، بنر تخفیف، مزایا |
| فروشگاه | تعداد محصول در صفحه، ستون‌ها، نوار افزودن به سبد |

همین تنظیمات در **سفارشی‌سازی وردپرس** هم هست و در همان گزینه (`bazar_settings`) ذخیره می‌شود؛ اپ و پیشخوان همیشه هماهنگ‌اند.

## API (`/wp-json/bazar/v1`)

| مسیر | دسترسی | کار |
|---|---|---|
| `GET /ping` | عمومی | نام سایت/نسخه؛ برای تست اتصال |
| `GET /schema` | مدیر | تعریف فرم‌ها و پالت‌ها |
| `GET /settings` | مدیر | مقدارهای فعلی + پالت نهایی |
| `POST /settings` | مدیر | `{"values":{...}}` ذخیره‌ی جزئی؛ کش افزونه‌های رایج پاک می‌شود |
| `POST /settings/reset` | مدیر | بازگشت به پیش‌فرض (نام سایت/لوگو دست‌نخورده) |
| `POST /preview` | مدیر | `{"values":{...},"path":"/"}` → آدرس پیش‌نمایش **ذخیره‌نشده** (۳۰ دقیقه اعتبار) |

لوگو و تصاویر را اپ با API خود وردپرس (`/wp/v2/media`) آپلود می‌کند و شناسه‌ی تصویر را ذخیره می‌کند.

## امنیت

- ورود فقط با Application Passwords (قابل ابطال، جدا از رمز اصلی)؛ فقط کاربر با `manage_options`.
- همه‌ی ورودی‌ها در سرور با `schema.json` پاک‌سازی می‌شوند؛ **هیچ CSS/HTML خامی** از اپ پذیرفته نمی‌شود. رنگ‌ها فقط hex معتبرند.
- توکن پیش‌نمایش تصادفی ۲۰ کاراکتری، موقت، فقط‌خواندنی، `noindex` و بدون کش.
- اپ CSP سخت‌گیر دارد (بدون اسکریپت/استایل بیرونی). رمز برنامه فقط در `localStorage` همان دستگاه است؛ هر وقت خواستید از پروفایل وردپرس ابطالش کنید.
- اگر قالب غیرفعال شود، API هم خاموش می‌شود.

## عیب‌یابی

| علامت | راه‌حل |
|---|---|
| «نام کاربری یا رمز درست نیست» ولی درست است | هاست هدر `Authorization` را حذف می‌کند. در `.htaccess` (قبل از بلوک وردپرس): `RewriteEngine On` ، `RewriteCond %{HTTP:Authorization} ^(.*)` ، `RewriteRule ^(.*) - [E=HTTP_AUTHORIZATION:%1]`. روی Nginx: `fastcgi_param HTTP_AUTHORIZATION $http_authorization;` |
| «رمزهای عبور برنامه» در پروفایل نیست | HTTPS فعال نیست، یا افزونه‌ی امنیتی آن را خاموش کرده |
| «قالب نسخه‌ی ۴ فعال نیست» | قالب بازار فعال نیست یا پیوند یکتا خراب است (اپ خودش `?rest_route=` را هم امتحان می‌کند) |
| پیش‌نمایش خالی | سایت/CDN فریم‌شدن را مسدود کرده (`X-Frame-Options`)؛ «باز کردن در تب جدید» را بزنید |
| تغییر ذخیره شد ولی سایت عوض نشد | کش CDN (مثل Cloudflare) را پاک کنید؛ افزونه‌های کش رایج خودکار پاک می‌شوند |

## توسعه

```bash
node tools/mock-server.mjs          # وردپرس شبیه‌سازی‌شده: http://localhost:8787/app/
                                     # user: admin   pass: abcd efgh ijkl mnop qrst uvwx
node tools/test-palette.mjs         # تضمین خوانایی روی هزار پالت تصادفی
python3 tools/phpcheck.py theme     # چک ساختار PHP (بدون نیاز به php)
python3 tools/e2e.py                # تست سرتاسری اپ با Playwright (سرور آزمایشی روشن باشد)
```

الگوریتم رنگ در دو جا پیاده شده و باید هم‌ارز بماند: `theme/bazar/inc/settings.php` (`bazar_palette`) و `app/js/color.js` (`derive`).
هنگام تغییر، `tools/test-palette.mjs` را اجرا کنید.

## ساخت فایل نصبی اندروید (APK) با گیت‌هاب

1. در ریپو: **Actions ← android ← Run workflow** (روی `main`). حدود ۸ تا ۱۵ دقیقه طول می‌کشد.
2. بعد از سبزشدن، وارد همان اجرا شوید و از بخش **Artifacts** فایل `sungold-admin-apk` را دانلود کنید. داخل zip فایل `sungold-admin.apk` است.
3. روی گوشی اندروید فایل را باز کنید و اجازه‌ی «نصب از منبع ناشناس» را بدهید.
4. اختیاری: تگ بزنید (`git tag v1.0.0 && git push --tags`) تا APK در بخش **Releases** هم بیاید و لینک مستقیم داشته باشید.

نکته‌ها:
- این APK با کلید debug امضا می‌شود؛ برای استفاده‌ی شخصی/تیمی کافی است. برای **Google Play** باید کلید امضای release ساخته و به workflow اضافه شود.
- **آیفون:** فایل نصبی رایگان ممکن نیست (حساب Apple Developer و Mac/امضا لازم است). راه رایگان: Safari ← Share ← Add to Home Screen (همان PWA).
- نام و شناسه‌ی اپ در `capacitor.config.json` و آیکن/اسپلش در پوشه‌ی `assets/` است.
- اگر ساخت قرمز شد، متن مرحله‌ی قرمز در Actions را برای رفع خطا بفرستید.

## وضعیت تست

- تست‌های اپ (۲۵ بررسی سرتاسری، CSP، موبایل/دسکتاپ) و الگوریتم رنگ: ✔ روی سرور آزمایشی.
- **ساخت APK در گیت‌هاب هنوز اجرا نشده** (اینجا اینترنت و Android SDK نبود)؛ فایل‌های آن بر پایه‌ی روش استاندارد Capacitor نوشته شده.
- **PHP با وردپرس واقعی هنوز اجرا نشده.** CI در GitHub با `php -l` سینتکس را می‌سنجد؛ قبل از سایت اصلی، روی **staging** با `WP_DEBUG=true` امتحان کنید.
  ماژول‌های `inc/` طوری بارگذاری می‌شوند که خطای احتمالی آن‌ها سایت را سفید نکند (قالب با پیش‌فرض‌ها کار می‌کند).
